三、重新链接（relink）所需的材料
--------------------------------------------------------------------------------
LGPL v2.1 允许使用者修改上述库并重新生成本应用使用的 ffmpeg / ffprobe。
所需材料均已提供或可通过下列方式取得：

1. 完整源码：见第二节（FFmpeg）与第一节（LAME、libopus）。
2. 目标文件（object files）：执行
       KEEP_OBJECTS=1 ./scripts/build-ffmpeg-lgpl.sh
   会在 .build/ffmpeg-lgpl/objects/ 下生成 589 个 .o（**保留原目录结构**，
   libavcodec / libavformat 等目录下存在大量同名文件，不能扁平合并）
   与 8 个静态库：libavcodec.a、libavformat.a、libavutil.a、libavfilter.a、
   libswscale.a、libswresample.a、libmp3lame.a、libopus.a；
   其中 libmp3lame.a / libopus.a 同时平铺在 objects/ 根目录。
3. 替换为自定义/修改版库的步骤：
   a) 自行编译修改后的 libav*（静态库）或 libmp3lame / libopus；
   b) 将产物路径通过环境变量传入脚本，或直接修改脚本中的
      LAME_PREFIX / OPUS_PREFIX / 源码目录；
   c) 重新执行构建脚本，即可得到链接了新库的 ffmpeg / ffprobe；
   d) 用新二进制替换 VideoFlow.app/Contents/MacOS/{ffmpeg,ffprobe}
      （需要重新签名后才能在本机运行，命令见下）。

   替换后重新签名（先签嵌套二进制，再重签整个 app，否则 Gatekeeper 校验失败）：
       codesign --force --options runtime --timestamp \
         -s "Developer ID Application: <你的证书>" \
         VideoFlow.app/Contents/MacOS/ffmpeg
       codesign --force --options runtime --timestamp \
         --entitlements <VideoFlow 的 entitlements.plist> \
         -s "Developer ID Application: <你的证书>" \
         VideoFlow.app

   注：ffmpeg/ffprobe 本身不需要 disable-library-validation 权限；若上述
   entitlements.plist 仅含该权限，可对嵌套二进制省略 --entitlements。
